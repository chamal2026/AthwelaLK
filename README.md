# AthwelaLK

An AI-powered web application that provides Sri Lankan citizens with personalised, trackable document checklists and step-by-step guidance for government services.

## Technology Stack

- **Frontend:** Angular, TypeScript, SCSS
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **AI:** Ollama, Llama 3.2, RAG

## Frontend Setup

### Prerequisites

Install the following before running the frontend:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Angular CLI](https://angular.dev/tools/cli)

### 1. Clone the Repository

```bash
git clone https://github.com/chamal2026/AthwelaLK.git
```

### 2. Navigate to the Frontend Directory

```bash
cd AthwelaLK/athwelalk-frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
ng serve
```

### 5. Open in Browser

Visit:

```text
http://localhost:4200
```

The Angular development server automatically reloads when source files change.
